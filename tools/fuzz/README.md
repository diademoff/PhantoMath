# Случайные проверки решателя против sympy

Каждый скрипт генерирует задачи (seed — первый аргумент), решает их через `service.solve_request`
и сверяет ответ с независимым вычислением sympy. Печатает `WRONG`/`MISMATCH` при расхождении и
`FAIL` при исключении. Запуск из `backend`:

    .venv/bin/python ../tools/fuzz/equations.py 1

Нашли: двойной минус у отрицательного числителя (`from_sympy`), крах графика уравнения, таблицу
отсчётов вместо ответа у сокращающихся дробей, ошибку на выражениях, где буквы сокращаются.
