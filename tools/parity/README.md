# Паритет с Photomath 7.10.0: съёмка и сравнение

Эталон снимается с телефона (Pixel 4a, Photomath без входа) через adb и uiautomator.
Модель экрана: строка списка = основной шаг, страницы карусели (точки) = этапы, кнопка
«подробнее» = вложенный экран. Результат может состоять из нескольких карточек (способов).

```
python3 batch.py [id ...]     # снять задачи из tasks.json в cap/<id>.json (нужен телефон)
./crops.sh                    # контрольные листы набранного ввода (sheet_*.png)
./sheet.sh TASK CARD          # все скриншоты этапов одной карточки в один лист
../../backend/.venv/bin/python ours.py   # прогнать задачи через наш решатель
python3 compare.py            # собрать truth/12-parity-matrix.md
```

Правила: ввод проверяется повтором (два одинаковых прохода), снимки смотреть по контрольному
листу; сравнивается структура (строки → этапы → вложенность), формулировки авторские.
Наша вложенность может быть больше, но не меньше, чем у Photomath.
Не запускать две съёмки одновременно и не скроллить экран результата вниз (свайп вниз его закрывает).
Для сборки приложения на телефон нужны `SERIOUS_PYTHON_VERSION`, `SERIOUS_PYTHON_SITE_PACKAGES`,
`SERIOUS_PYTHON_APP` (как в Makefile) и `rm -rf app/build/serious_python_android`, иначе в APK
остаётся старый решатель.
