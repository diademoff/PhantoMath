# Ввод и живое решение: регрессии 2026-10-17

## Исправленные классы ошибок

| Причина | Поведение и проверка |
|---|---|
| Быстрые шаблоны содержали нередактируемые константы | `x²`, `x³`, `log₂`, `log₁₀`, `∛` создают общие шаблоны с редактируемыми слотами. Квадрат после операнда оставляет курсор снаружи. |
| Захват предыдущего токена не учитывал его роль | Дробь и степень не захватывают инфиксные знаки. Пустая дробь начинает с числителя. Скобки, корни, модуль не поглощают коэффициент. |
| Числовое слияние проверяло только левый токен | `8π`, `8e`, `π8` остаются отдельными операндами неявного умножения. |
| Навигация зависела от порядка хранения, а не представления | Для логарифма обход: основание → аргумент. Удаление показателя сохраняет основание. Тесты обходят вложенные слоты и цифры. |
| Размер и параметры скрывались в виде шаблона | Матрицы: 1–8 строк и столбцов, прямоугольные; размеры сохраняются при правках. Сумма: индекс, обе границы, слагаемое. |
| История хранила только представление для чтения | Восстановление AST в редактируемое дерево с сохранением группировки; неизвестные формы отклоняются без потери ввода. |
| Ответ вычислялся только при переходе на экран | Автоответ с паузой 450 мс, проверкой заполненности и поколением запроса. Переход к шагам использует готовый ответ. |
| Формальные кнопки без дополнительного содержания | Нет общего «Пояснить этапы», каталога «Все символы», статуса готовности и кнопок LaTeX. Действия и детали находятся в решении. |
| Общий fallback скрывал математическое правило | Квадратные уравнения: дискриминант и подстановка, включая π; тождество sin²(u)+cos²(u) имеет отдельное объяснение. |
| Предпросмотр использовал intrinsic layout для формул | Длинные точные корни прокручиваются горизонтально без обрезания и уменьшения шрифта. |

## Граница проверки

`test/natural_input_test.dart` проверяет операции редактора;
`test/history_restore_test.dart` — восстановление, группировку и матрицы;
`test/live_answer_test.dart` — автоответ, незаконченный ввод, кэш и устаревшие ответы.

через настоящую клавиатуру и встроенный решатель, включая историю и матрицу 4×3.
Исчерпывающая ручная проверка всех символов, TalkBack и всех математических правил
этими сценариями не заменяется. Список поддерживаемых правил не универсален.
