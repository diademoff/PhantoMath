# app

Flutter-клиент: ввод выражения, отправка в бэкенд, показ пошагового
объяснения. Целевая платформа — Android.

Формат обмена с бэкендом — контракт Photomath
(`truth/03-solver-contract.md`): на входе `CoreNode`, на выходе
`CoreSolverData` с вертикальными шагами.

## Требования

| Что | Версия |
|---|---|

| JDK | 17+ (для Gradle) |

## Запуск с бэкендом

Бэкенд поднимается отдельно (см. `../backend/README.md`). Адрес передаётся
при сборке; по умолчанию — `10.0.2.2:8000`, это адрес хоста, видимый с
эмулятора Android:

```bash
flutter run --dart-define=MYMATH_API=http://10.0.2.2:8000
```

На физическом устройстве нужен реальный IP машины, а не `10.0.2.2`.
Эмулятор также должен видеть бэкенд: `python3 -m http.server` в этом
режиме не подойдёт, нужен запуск с `--host 0.0.0.0`.

| Файл | Что внутри |
|---|---|
| `lib/main.dart` | Экран ввода и результата |

| `lib/src/render/latex.dart` | `CoreNode` → LaTeX для `flutter_math_fork` |
| `test/model_test.dart` | Разбор ответа, перевод в LaTeX, поведение клиента при ошибках |

## Как это устроено

**Рендер.** Формулы рисует `flutter_math_fork`: наш `nodeToLatex` переводит
дерево в строку LaTeX с позиционными плейсхолдерами `$0`, `$1`, … — по
одному на ребёнка. Это позволяет разводить аргументы по разным местам:
`\frac{$0}{$1}` кладёт первого в числитель, второго в знаменатель.
Результат — «сырой» LaTeX без обёрток `$…$`: парсер (`KaTeX`) не принимает
`$` внутри формулы. Свой рентер дробей и корней не писался сознательно:
это отдельный проект.

**Ввод.** Поле принимает строку в протоколе Photomath и отправляет её на
`/parse`, а дерево — на `/solve`. Так парсинг живёт в одном месте (бэкенд),
и фронт не расходится с оригиналом в трактовке ввода.

**Ошибки.** `422` от бэкенда — это «задача не решилась», а не сбой: показываем
текст пользователю. `5xx` и сетевые сбои идут в `SolveFailure` с кодом.

**Неизвестные типы узлов** не роняют разбор: подставляется `TEXT` с
сохранением значения, а `CoreNode.hadUnknownTypeIn` позволяет их отследить.
Расхождение с бэкендом должно быть заметным, а не тихим.

## Чего ещё нет

- Клавиатура редактора с 128 операторами Photomath (`truth/data/enums.json`
  → `editor_operators`).
- Графики.
- Тема, тёмный режим, локализация интерфейса (данные для неё готовы в
  `res/values-*` оригинала, но в этом проекте не переведены).
- Микро-анимации шагов: контракт несёт `color` и `crossed` в узлах, но
  рендер их пока игнорирует.
