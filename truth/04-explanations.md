# 04. База объяснений

## Что это

3252 уникальных ключа объяснений, каждый с шаблоном на **9 языках**
(en, de, es, fr, it, pl, pt, ru, uk). Это весь словарь прозы, которым
Photomath комментирует каждый шаг решения.

Файл: `truth/data/explanations.json` (2.3 МБ).

```jsonc
"abs_const_long": {
  "arity": 3,
  "templates": {
    "default": "Since ARG1, the [absolute value|f20b5152-…] of ARG2 is ARG3",
    "ru":      "Поскольку ARG1, абсолютное значение ARG2 равно ARG3",
    "de":      "Da ARG1 ist der absolute Betrag von ARG2 gleich ARG3",
    "es":      "Como ARG1, el valor absoluto de ARG2 es ARG3"
  }
}
```

Покрытие локалей: default(en) 3252, de 2834, es 2852, fr 2924, it 2834,
pl 2883, pt 2870, ru 2832, uk 2832. Остальные ~400 ключей на язык — fallback
на английский, это нормально.

## Как извлечено

Строки **не** лежат ни в одном `res/values/*.xml`, поэтому apktool их молча
выбросил. Они лежат в `resources.arsc` как TYPE_STRING ресурсы и читаются
только нативным кодом по имени.

Цепочка (проверена по коду):

1. `CoreRichText.type` приходит из решателя.
2. `c/a/a/l/g/c0.java:35` → `j.j("step_", type)` → `"step_" + type`.
3. `Resources.getIdentifier("step_abs_const_long", "string", pkg)` → `getString()`.

Ассеты `assets/keys.txt` дают перечень 3020 ключей + арность, но **не** тексты.

Резолвер: `truth/data/arsc_resolve.py`. Он обходит `ResTable_package` →
`ResTable_type` для типа `string`, выбирает конфиг по языку
(`ResTable_config.language`) и склеивает `keyString` → значение из глобального
пула.

### Две нестандартности, которые пришлось обойти

Их стоит знать, если будете править скрипт:

1. **Два разных пула имён.** В `ResTable_package` имена типов лежат в пуле по
   смещению `+268` (`typeStrings`), а имена ресурсов — в пуле по `+276`
   (`keyStrings`). Это разные пулы (8911 и 21 строка). Использование одного
   для обеих задач молча теряет все ресурсы.

2. **aapt2 этой сборки не использует AOSP-layout `ResTable_entry`.** Вместо
   `{size u16, flags u16, key u32, data u32}` он пишет:
   - по адресу `headerSize` — плоский массив `u32`-смещений, по одному на запись;
   - по адресу `entriesStart` — массив 16-байтных записей
     `{ uint32 entry_size(=8); uint32 key; Res_value value }`.

   `Res_value` **инлайнится** сразу после 8-байтного заголовка записи.
   Проверено на `abc_action_bar_home_description` → «Navigate home».

Скрипт `arsc_pools.py` (обход пулов) и `arsc_resolve.py` (полное разрешение) —
в `truth/data/`.

## Синтаксис шаблона

Из `c/a/a/l/g/c0.java`:

```
ARG(\d+)                       Pattern b   — плейсхолдеры аргументов
\[(.+?)\|(.+?)\]              Pattern b   — кликабельная ссылка
\n?\[([^|]+)]$                 Pattern c   — хвостовой «ярлык» без ссылки
`...`                          Pattern     — термин (в MathTextView)
```

### `ARGn`

Подставляется `args[n-1]`, отрендеренный как математика. Например
`"Since ARG1, the … of ARG2 is ARG3"` + args `[x, |−7|, 7]` →
«Since *x*, the absolute value of *−7* is *7*».

### `[label|uuid]` — переключатель способа решения

Кликабельный фрагмент, подчёркнутый, цвет accent. `uuid` (36 символов) —
идентификатор альтернативного метода решения; по нему приложение умеет
показать другой путь.

Найдено **426 уникальных UUID** и **1762 ссылки** суммарно.

Топ-лейблы: `term` (81), `denominator` (57), `domain` (48), `numerator` (44),
`power` (35), `exponent` (28), `fraction` (27), `base` (25).

Практический вывод: это **объяснительная семантика**, а не форматирование.
Наш рендер должен уметь показать «нажмите, чтобы увидеть другой способ».

### Хвостовой `[label]`

`Pattern c` = `\n?\[([^|]+)]$` — метка в конце строки без ссылки. Убирается
из вывода, возвращается отдельным значением (`str2` в `c0.a(...)`).

## Что из этого берём

Тексты — **наша самая ценная находка**. Они:

- полные (3252 ключа, не выборка),
- уже переведены на 9 языков, включая русский и украинский,
- привязаны к арности, так что не нужно гадать о формате аргументов.

Рекомендация: **перенести `explanations.json` в наш проект как есть** и
использовать ключи из `keys.txt` как чек-лист покрытия решателя. Наш
Python-решатель при генерации шага обязан выдавать `CoreRichText(type, args)`
с ключом из этого словаря — тогда тексты подставятся автоматически, и мы
сразу получим многоязычность.

Лицензионная оговорка: это извлечённые из коммерческого приложения строки.
Для личного/исследовательского использования — ок. Для публикации —
нужно решить отдельно.
