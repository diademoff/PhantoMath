## Состояние кода

| Часть | Состояние |
|---|---|
| `backend/` | работает: 593 теста (в т.ч. корпус 120 задач), ruff, mypy strict чисто; модули: арифметика, дроби, степени/корни/логарифмы, тригонометрия (прямые/обратные/гиперболические функции, единицы угла, тождества, уравнения сериями), модуль/знак/пол, уравнения (со способами, тождествами и модулем), неравенства, системы 2×2, определители и операции над матрицами, производные, пределы, интегралы, суммы, комбинаторика, комплексные числа, векторы, команды; слой sympy; глоссарий; эндпоинт `/graph` |
| `app/` | редактор (тап), клавиатура, команды, способы решения, определения по ссылкам, векторы/системы/определители, операции над матрицами, векторные операции, график, блокнот, тёмная тема; `flutter analyze` чисто, 76 тестов, debug APK собран |
| Сквозной сценарий | арифметика и уравнения: ввод → `POST /solve` → шаги с русскими пояснениями (`2x+3=7` → `x=2`) |

Модули решателя (`backend/mymath_backend/solver/`) регистрируются по типам
узлов; `registered_types()` даёт покрытие. Реализованы арифметика
(`arithmetic.py`), дроби (`fractions.py`), степени/корни/логарифмы
(`powers.py`), тригонометрия (`trigonometry.py` — прямые, обратные и
гиперболические функции, единицы угла `DEGREE`/`RADIAN`), уравнения (`equations.py`), неравенства (`inequalities.py`),
системы 2×2 (`systems.py`), определители (`matrices.py`), производные
(`derivatives.py`), пределы (`limits.py`), интегралы (`integrals.py`), суммы
(`series.py`) и комбинаторика (`combinatorics.py`). Команды (`commands.py`) —
это `CoreAction` Photomath: `factor`, `expand`, `simplify`; `POST /solve`
принимает необязательное поле `action`. Уравнения возвращают **несколько
способов решения** (квадратное — формулой и, если корни рациональны,
разложением): это отдельные записи вертикальной ветки, переключатель —
`selectMethodText`. Мост `sympy_bridge.py` переводит дерево в sympy и
обратно. Языки пояснений — только русский и английский
(`api.normalize_locale`), см. `09-decisions.md`.

## Правила работы с этим проектом

- **Не указывать сроки и оценки времени** ни в одном документе и ни в одном
  ответе. Разрешены только приоритеты и оценки сложности.
- Архитектурные и продуктовые решения **не принимать самостоятельно** —
  задавать вопросы пользователю. Решения фиксировать в `06-plan.md`
  → «Принятые решения».

## Как восстановить контекст

1. Прочитать этот файл.
2. `01` → `02` → `03` (это ядро: без `03` писать backend бессмысленно).
3. `06-plan.md` — план работ.
4. Инструменты: `python3 truth/data/arsc_resolve.py <apk>/resources.arsc out.json`

REQ: REA MCP потребовал `REA_JADX_MCP_JAR`; JAR скачан в
`~/tools/rea-jadx/jadx-headless-mcp-0.7.1-all.jar` и прописан в
`~/.config/opencode/opencode.jsonc` (chezmoi-источник:
`~/arch/dotfiles/chezmoi/dot_config/opencode/opencode.jsonc`).
**После рестарта OpenCode** инструменты REA Android-семейства заработают;
до этого разбор выполнен через JADX CLI + apktool напрямую (см. `01`).
